# Project 2 — Phase 1: LangChain + LangGraph Fundamentals

This folder contains my learning showcase page for LangChain and LangGraph fundamentals, created as part of the DevSynt AI Engineer Internship.

## How to Run

Open `index.html` in a browser. Keep `index.html` and `style.css` in the same folder so the styling loads correctly.

## What I Learned

I learned the basics of LangChain, including prompt templates, chains, LCEL, output parsers, memory, and tool calling. I also learned how LangGraph represents flexible workflows using nodes, edges, conditional decisions, and state. Finally, I learned the purpose of orchestrator agents and why our upcoming project needs routing between specialized agents.
